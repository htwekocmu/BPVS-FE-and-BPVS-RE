# BPVS-FE-and-BPVS-RE or Bayesian Panel Variable Selection Models in R
This repository provides the R code, sample data, supplementary materials, and implementation guide supporting our published paper, Bayesian Panel Variable Selection under Model Uncertainty for High-Dimensional Data (https://www.mdpi.com/2225-1146/14/1/3). The files are provided to facilitate replication of the empirical results and implementation of the proposed BPVS methodology.
